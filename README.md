## **TourMap**

Full-Stack Campground Review Platform

TourMap is a full-stack website where users can create and review campgrounds. To add or review a campground, users must have an account.


## Features

🌐 Public Access – Everyone can view campgrounds and reviews without signing up.

🔐 Secure Authentication – Users must log in to create, edit, or delete campgrounds and reviews.

✏️ User-Specific Actions – Users can only modify or delete campgrounds and comments they created.

☁️ Persistent Data – All data is stored on MongoDB hosted on AWS.
